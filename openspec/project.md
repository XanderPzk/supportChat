# SupportChat

Proyecto de prueba técnica para construir un chat de soporte en tiempo real con:

- Backend: Java 21 + Spring Boot.
- Frontend: React.

Objetivo MVP:

1. Intercambio de mensajes entre cliente y agente en vivo.
2. Manejo de orden consistente y deduplicación ante reconexión/reintentos.
3. Registro explícito de decisiones técnicas y trade-offs.
